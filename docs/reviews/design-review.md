# Design review

The 100 simulated cases are hypotheses grounded in the specified journeys, with actual generated-route existence checks. They do not measure satisfaction or comprehension.

Implemented improvements: grouped reader controls, complete-chapter HTML fallback, original section-anchor compatibility, explicit association labels, passage-based bookmarks, mobile contents/related disclosures, four contrast palettes, reduced motion, visible sources and an offline draft editor preserving unknown fields.

Still to verify: live focus/return journeys, real touch devices, screen-reader behaviour, ambiguous aliases against the complete corpus, source links and editorial release/rollback. No fictional participant quotations or satisfaction percentages are reported.
