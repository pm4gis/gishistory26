# Approved homepage and direct navigation

Base: production commit 8dc7e2d10f88d7cb703bd8114a202f04eee38989. This release implements the second homepage image preview explicitly approved on 20 October 2026, plus the subsequent request to replace the Explore menu with individual headings.

The homepage uses a static full-width Landsat observation of Tasman Glacier from 30 December 1990. A readable title, chapter action, timeline link and five measured publication statistics sit over the image. The page continues with the accepted Tuki map, a separate text introduction and the documented Intergraph workstation photograph in a staggered composition. The original image binaries and metadata are unchanged. Each image has a direct route to its existing credit and source record. The workstation remains representative period equipment, with its original record explaining that its installation location is unknown.

The six chapter links form a text index, with all 44 existing homepage chapter anchors retained in the contents disclosure. All eight themes remain available as plain text links. Existing reading progress can still expose Continue reading. The short history is removed from the homepage, shared menus, footer and chapter-catalogue invitation. Its accepted page and sources remain available through the existing About page and discovery files. No chapter or source prose is changed.

Desktop and mobile navigation expose Chapters, Timeline, People, Organisations, Themes, Datasets, Connections, Publications, Search, About and Contribute. People opens the existing browser with the Person filter. Organisations opens the same browser with Organisation, Agency, Business, Council and Community filters. The mobile menu uses a single native disclosure, supports keyboard access and Escape, closes on outside interaction, and scrolls within the viewport. All appearance palettes and modes remain available.

The previous animated hero, slider, playback controls, compact image cards and nested Explore disclosure are removed from the rendered interface. Tests that required those superseded presentations are replaced by checks of the approved static composition, original image destinations, direct navigation, chapter anchors and no-JavaScript reading. Detailed image selection and crop checks remain for the unchanged full chapter catalogue and reader navigation.

Verification includes npm ci, all 159 automated tests, production build and preservation/media/link/sitemap checks. Browser suites cover the approved composition at 1440, 1280, 1181, 1024, 768, 390 and 320 px; image and chapter links; all 44 anchors; filtered navigation destinations; text resize and no-JavaScript content. Shared menu checks cover keyboard access and all five palettes in both modes. Existing first-visit journeys retain search, timeline, network, publication filters, local PDF bytes and contribution checks, with WCAG A/AA axe audits across nine routes. Publication-return and catalogue image checks remain in CI. Screenshots and machine-readable outcomes are retained as workflow artifacts.

Automated Chromium and axe checks do not establish compatibility with every browser, device or assistive technology. This release changes presentation and navigation only; the historical cutoff remains 31 December 2025, and accepted records, relationships, exclusions, archive structure and PDF hosting remain unchanged.
