## Image and rights handling

- Each Commons file page records the image date, source or author, and the licence used in the image detail page. The detail pages include the source page, direct source image and licence links.
- The Silverpeak JPEG is stored from its Commons source original. The Wiri image uses a 3840 × 3745 Commons rendition, with its 6760 × 6593 master linked from the detail page. The North Island map’s 8192 × 9884 master is 93.66 MB; its local source copy is the 1920 × 2317 Commons rendition so it stays within the site’s 25 MiB per-asset limit. Each local JPEG is stored byte-for-byte from the source file or rendition.
- Responsive display and card files are WebP derivatives resized without cropping. They do not replace the local JPEG source copies.
- No historic image is presented as a GIS screen. The Silverpeak map is described as a paper cadastral record map; the 1981 counties map is described as an administrative map; and the 1982 Wiri image is explicitly distinguished from the 1977 Clutha–Alexandra production work.
- No people-profile images or story prose were added or rewritten. The three existing passage records only gained an inline figure block after an existing paragraph.
