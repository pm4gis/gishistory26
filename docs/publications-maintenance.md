# Maintaining publications

`src/lib/publications.mjs` combines the existing `contributed-primary-sources.mjs` and `chapter-documents.mjs` registers for catalogue presentation. Keep original metadata and binaries in their existing registers and paths. Add presentation fields through this shared view rather than starting another document register. Undated reference material uses a null publication date and has no dated timeline entry. Keep original publication dates and precision separate from the archive date. Preserve original filenames in metadata, original bytes and SHA-256. Use descriptive, stable filenames in `public/assets/historical/documents/`; a viewing PDF is a labelled derivative, never a replacement for a PowerPoint original.

For each entry, supply its title, creator, publication date, type, description, page count, size, checksum, provenance, rights note, stable publication URL, original and viewer paths, cover image, card thumbnail, themes and supported record IDs. `/publications/` and `/publications/[slug]/` generate from these records. Existing `/sources/documents/` identities remain usable and link to the public viewing pages. The sitemap includes both routes, and Pagefind indexes the complete publication descriptions and connected subjects.

Render covers from originals, retaining legibility. Put documentary illustrations into the existing image catalogue with source page, date, credit, original render, WebP derivatives, checksums and an exact paragraph anchor. Add their decisions to `docs/media/chapter-image-alignment-wave2-20261011.csv`. Publication illustrations are excluded from automatic chapter-card selection to preserve existing accepted cards.

Add historical writing to source-backed passage blocks, preserve existing paragraph IDs and chronology, and link the publication event to the passage and records. Preserve the 31 December 2025 public timeline cut-off. A strategy's future roadmap is not evidence of completion. Check people against names and aliases, preserve exclusions and limited biographies, and document only supported relationships. Retain any third-party map, software and imagery credits; contributor publication authorisation does not establish a general open reuse licence.

Run `npm ci`, `npm test`, `npm run build`, the editorial-exclusion check and desktop/mobile browser journeys. Content baseline changes require an additive comparison to the current accepted revision and a reviewed manifest update. Verify every original download checksum, viewer, thumbnail, source route, chapter placement and production commit. Publish through a branch and pull request, then verify Cloudflare production and the public hostname.
